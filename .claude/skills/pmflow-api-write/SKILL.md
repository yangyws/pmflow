# 用 API 權杖寫資料進 PMFlow

**完整內容在 `D:\NewProject\pmflow-git\docs\API-WRITE.md`，先讀那一份。**
這裡只是指標 —— 那份文件是所有 AI 共用的，內容不要複製到這裡，
兩份各自維護一定會走鐘（同 `CLAUDE.md` / `GEMINI.md` 只有一行指回 `AGENTS.md` 的道理）。

動手前必須知道的三件事，其餘看那份文件：

1. **不要直接寫資料庫。** 排程重算、閉包表重建、對外詢問狀態、活動紀錄與通知
   全都在 API 層做，繞過去的資料在畫面上會是壞的。
2. **權杖的權限完全等於發它的那個人**，而且還要過**關係人判斷**（Ref: CR-130）——
   拿權杖去改別人開的任務照樣 403。這是最常見的失敗原因。
3. **會再跑第二次的東西一律寫成可重複執行的腳本**（已建立的要認得出來並跳過）。
   這是專案硬規定，見 `AGENTS.md`。

權杖本身只有人能產（網站 →「帳號設定」→「API 權杖」，明文只顯示一次）。
**AI 不要嘗試自己生一把**，也不要把權杖寫進 repo。
